# Ativos originais

Esta pasta receberá os materiais brutos enviados pelo cliente. Sugestão de subpastas:

- marca — logotipo, símbolo, manual e arquivos vetoriais
- retratos — fotos profissionais do Dr. Adriano
- consultorio — ambientes, equipamentos e fachada
- equipe — fotos individuais e coletivas
- videos — gravações originais e depoimentos autorizados
- referencias — exemplos visuais aprovados pelo cliente
- documentos — comprovações e informações profissionais

## Regras

- Preservar os arquivos originais sem sobrescrever.
- Não armazenar imagens, exames ou dados identificáveis de pacientes sem autorização e tratamento jurídico adequado.
- Registrar autorização de uso de imagem quando houver pessoas identificáveis.
- Usar nomes descritivos, sem acentos e em letras minúsculas.
- Exportar apenas versões tratadas e otimizadas para a futura pasta public do site.
