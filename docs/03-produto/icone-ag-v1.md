# Ícone AG — proposta 1

Criado com a ferramenta integrada imagegen, usando `3.png` como referência tipográfica. Arquivo: `public/brand/adriano-ag-icon-v1.png`.

Para o cabeçalho branco, a versão escura `3.png` é a mais legível. `4.png` é a versão branca para fundos escuros; `2.png` usa azul claro e subtítulo branco. As três possuem transparência e margens grandes, que precisam ser consideradas ao preparar o logo para o cabeçalho.

O ícone é uma proposta nova com as iniciais AG, sem a descrição da especialidade. Aplicado ao favicon (64 px), ícone Apple (180 px) e manifest (192 e 512 px). A logo 3.png foi aplicada ao cabeçalho, e a 4.png ao menu móvel e rodapé. O componente BrandLogo usa uma janela SVG para ocultar as margens transparentes, preservando os PNGs originais.

## Prompt utilizado

Use case: logo-brand. Create ONE finished square website favicon/app icon for Dr. Adriano Germano, based on the supplied reference logo. The reference is a typography reference only; do not reproduce the full wordmark. Subject: an exceptionally clear, elegant AG monogram using the recognizable high-contrast serif capital A and rounded serif capital G from the reference, optically balanced and subtly interlocked while both letters remain unmistakable. Adapt hairlines to medium thickness so this icon remains readable at 32px; generous open counters, restrained simplicity. Composition: centered single large monogram occupying approximately 72% of a square canvas with equal generous safe margins, designed for circular and rounded-square cropping. Colors: ivory-white letters on a solid deep navy background #223853, matching the website header identity. Flat vector-like graphic with clean sharp contours; no texture, no lighting, no gradients, no shadows, no bevel, no mockup, no border, no ornament, no tooth or medical symbol. Text: only the two capital initials AG; no Dr., no full name, no subtitle. Deliver a single square high-resolution icon, not a presentation sheet or multiple options.
